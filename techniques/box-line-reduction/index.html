Box-line reduction

In a row or column, a digit is limited to one box, so it leaves the rest of that box. Level: Hard.

Box-line reduction is the mirror image of pointing pairs. This time you study a row or a column. Suppose that in row 4 the only cells that can still hold a 2 all lie inside the same box. Row 4 must have a 2, so it will be one of those cells, which means that this box gets its 2 from row 4. Every other cell of the box, on the other two rows, can drop the 2.

It is also called claiming (the line claims the digit for itself) or locked candidates, type 2. It is a little harder to see than a pointing pair, because the eye groups cells by box more easily than by line.

How to spot it

  1. Take one row or column and one digit that it still needs.
  2. Mark the cells of the line where the digit is still a candidate.
  3. If all of them (two or three cells) fall inside one box, the line has claimed the digit in that box.
  4. Remove the digit from all the other cells of the box.
  5. Look for the single that the removal exposes.

A worked example

This position comes from a real puzzle made by this site. Rows are counted from the top and columns from the left, so R2C9 means row 2, column 9. Small digits are candidates.

Read along the shaded line: the digit can go only in the amber cells, and they share a box. The red candidates, in the same box but off the line, are removed.

Why it works

The line must contain the digit, and all its possible places on the line are inside one box. So that box receives the digit on this line. A box holds each digit once, so the digit cannot also appear in the box on a different line.

Another example

The second position uses the other direction. The test is always the same two questions: where can the digit go on this line, and are those cells all in one box?

Mistakes to avoid

  • Mixing it up with pointing pairs. Ask where the restriction comes from. Candidates confined to a line within a box: clean the line. Candidates confined to a box within a line: clean the box.
  • Checking only rows. Columns claim digits just as often.
  • Missing it because the line still has many empty cells. The number of empty cells does not matter; only the cells where this one digit is possible count.

When to look for it

After a round of pointing pairs, go line by line. A quick way: for each row, look at the three segments where it crosses the boxes. If a digit is missing from the row and is already ruled out of two segments, it is locked in the third, and the rest of that box can be cleaned.

Practise it

Play a puzzle at the Hard level, where this technique is needed. The first tap on Hint tells you when it is the step to look for.
